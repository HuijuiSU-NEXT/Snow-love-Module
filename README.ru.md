# Snow-Love Module

> Модуль скрытия в один клик — прошил и пользуйся.

## Что это

Один модуль, который объединяет типовые компоненты противодействия детекту
и автоматически готовит окружение после прошивки.

| Компонент | Назначение |
|---|---|
| Zygisk Next | Среда Zygisk |
| LSPosed | Фреймворк модулей |
| HMA | Скрытие списка приложений |
| PIF | Исправление Play Integrity |
| Правила SUSFS | Скрытие путей и точек монтирования |

Цель одна: **меньше ручной работы, меньше ошибок**.

## Возможности

- **Установка в один клик** — один zip, одна прошивка
- **Автоконфигурация** — списки разрешений, denylist, скрытие монтирований
- **Откат** — поставляется `uninstall.sh`, не оставляет следов
- **Совместимость** — KernelSU / SukiSU / APatch, лучше всего с Hybrid Mount

## Установка

1. Убедитесь, что есть root на уровне ядра (семейство KernelSU)
2. Сначала установите мета-модуль **Hybrid Mount**
3. Менеджер → Модули → Установить → выбрать этот zip
4. Перезагрузка

## Совместимость

| Окружение | Статус |
|---|---|
| KernelSU / SukiSU | ✅ Поддерживается |
| APatch | ✅ Поддерживается |
| Magisk | ⚠️ Не проверено |
| Ядра 4.x вне GKI | ⚠️ Часть функций недоступна |

## Отказ от ответственности

Модуль предназначен для **изоляции среды и защиты приватности на личном устройстве**.
Не используйте его для обхода законных систем контроля рисков.

Автор не несёт ответственности за блокировки, потерю данных или сбои устройства.
Прошивка связана с риском — сначала сделайте резервную копию раздела boot.
